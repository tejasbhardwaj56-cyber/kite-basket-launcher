# kite-basket-launcher

One static page with no data in it. A link's `#fragment` carries a trade basket, and the browser never sends the fragment to
this host. The page shows the orders and, on the user's tap, opens them in Kite Publisher (`kite.zerodha.com/connect/basket`).
Kite then asks the user to log in and to tap Place.

The page contains no order data, credentials, or tracking.
